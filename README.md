# First break prediction using convolutional neural networks

[Barbosa, R.D](http://lattes.cnpq.br/3378048344015204), [Cerqueira, A.G](http://lattes.cnpq.br/4993793853330521),[Souza, W.E]( http://lattes.cnpq.br/2250287053898908),[Porsani, M.J]( http://lattes.cnpq.br/1428637808064409)

[![DOI](https://img.shields.io/badge/DOI-10.13140%2FRG.2.2.19195.08481-blue)](https://doi.org/10.13140/RG.2.2.19195.08481) [![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.16764353.svg)](https://doi.org/10.5281/zenodo.16764353)

This project presents a methodology for first-break picking in pre-stack seismic data using a variation of the U-Net convolutional neural network, known as the 1D U-Net. The seismic traces were labeled using the Dynamic Time Warping (DTW) algorithm, a method commonly used for comparing time series. The use of DTW for automatic labeling is considered a key contribution of this research.

This work were presented on 18th International Congress of the Brazilian Geophysical Society & Expogef. To see more information about this project, see this: [First Break Prediction in land seismic dataset using U-Net convolutional neural network](https://www.researchgate.net/publication/374951316_First_break_prediction_in_land_seismic_dataset_using_U-net_convolutional_neural_network)

## 🧠 Preprocessing

### Spherical Divergence Gain
When seismic waves travel through the Earth, their energy spreads out over an expanding spherical front. Because of this spreading, the wave's amplitude naturally decreases as it moves farther from the source. This means that seismic signals recorded at larger distances (offsets) tend to be weaker. To correct for this effect, a process called spherical divergence gain is applied to the seismic data. This gain amplifies the signal amplitudes at greater distances to compensate for the natural decay caused by geometrical spreading. Applying spherical divergence gain helps restore the strength of seismic signals from far offsets, improving their visibility and making the data more consistent across different distances. This enhancement is important for better interpretation and analysis of seismic events.

![gain](/figures/traces_with_and_without_gain.png)

### Shift Function
After generating the labels using the Dynamic Time Warping (DTW) technique, a data augmentation step was performed using a shift operation. This operation consists of translating the first-break signal to later time samples, simulating larger source-receiver offsets. This phase is essential for training the network, as first-break signals at larger offsets tend to have lower amplitude and fewer samples, making them more likely to be confused with random noise or null traces in the seismic data. Following the shift operation, the training and testing dataset was quadrupled—a total of 14,670 new traces were generated from the original 4,890 traces, resulting in a final dataset of 19,560 traces.

![shift](/figures/traces_with_and_without_shift.png)

### Labeled Dataset

The dataset was annotated into two classes: class 0, assigned to all values preceding the first break (highlighted in red), and class 1, assigned to all values following the first break (highlighted in green). To determine the prediction yielded by the U-Net model, the index corresponding to the first occurrence of class "1" in the prediction array is identified, which represents the estimated location of the first break.

![dataset](/figures/seismic_data_picks.png)

## ✨ Evaluation Metrics
Training and validation metrics are used to assess the model's performance and its ability to generalize. They are computed based on the network’s predictions compared to the ground truth labels. In this work, the following metrics were used:

**Accuracy**: Represents the overall proportion of correct predictions out of the total. While it offers a general view of model performance, it can be misleading in cases of class imbalance. **Recall**: Represents the proportion of true positives (TP) out of all actual positive instances. It becomes crucial when avoiding false negatives (FN) is a priority. 

**F1 Score**: The harmonic mean of precision and recall, providing a balanced metric.

![metrics](/figures/metrics.png)

The DiceCELoss is a composite loss function commonly used in segmentation tasks, especially when dealing with imbalanced datasets. It combines the Dice Loss, which measures the overlap between predicted and true regions, with the Cross-Entropy Loss, which focuses on pixel-wise classification accuracy. While Cross-Entropy helps the model learn class-specific features, Dice Loss ensures better shape and boundary alignment. This hybrid approach leads to more robust training, especially in cases where the target classes occupy a small portion of the input.
